Оптимизация TTFB

Обновление железа

Обновление железа поискового движка

  • latency на высоких перцентилях стал менее разрозненным
  • на TTFB эффекта не дало – latency изначально был невысок

Обновление железа SSR

  • latency стал меньше на 25% (60ms -> 45ms)
  • на TTFB так же отразилось

Оптимизация TTFB

Обновление зависимостей

Обновление PHP

  • переехали c PHP 7.4 на PHP 8.1
  • latency формирования страниц уменьшился на 50ms

Обновление Node.js

  • переехали c Node.js 20 на Node.js 24
  • latency ответа SSR уменьшился на 24% (10-15ms)
